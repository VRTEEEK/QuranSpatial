# Challenge day 1 — 4 October 2026

Everything in this file is challenge work, committed with real timestamps on the `challenge`
branch and mirrored to the public repository by `tools/sync-public.sh`.

## What was built

- **`tools/sync-public.sh`** — mirrors the private HEAD into the public checkout minus the
  never-public list, aborting if an excluded file or any translation/tafsir passage would be copied.
- **`tools/fetch-sources.py`** — downloads the raw Quranpedia files (books 1947 and 27824, the
  similar-ayat dump), verifies their pinned SHA-256, re-extracts the two local text files with the
  recorded deletion-only rules and verifies the pinned text hashes. Re-running it on this machine
  reproduced both local files byte for byte. The texts themselves stay out of the repository.
- **`Packages/AskCore`** — a Swift package (macOS 26 / visionOS 26), separate from the app target:
  - `Corpus`: Surah 55 records keyed by ayah: Saheeh International translation (book 1947), its
    translator's footnotes (from the raw 1947 file, verified against the extracted file's recorded
    raw hash and re-extracted to confirm the bundled text), and the Mukhtasar passage (book 27824).
    Same hash checks as the app.
  - `QuestionRouter` with two implementations: `FoundationModelsRouter` (on-device, a `@Generable`
    enum, permissive content-transformation guardrails) and `RuleBasedRouter`. The engine records
    which one routed, and falls back to the rules when the model refuses or is unavailable.
  - `Retriever`: anchor ayah first, always. `Answer`: verbatim passages with source lines, an empty
    lead, and a decision: answered / referred (rulings → a scholar) / declined (off-topic).
  - **`qs-ask`** CLI: `qs-ask --ayah 13 "why does this repeat?"` prints JSON then readable text.
- **`tests/eval/questions.json`** — 30 questions (10 meaning, 5 word, 5 repetition, 5 ruling,
  5 off-topic) across 19 ayat; `EvalTests` runs both routers and writes `tests/eval/results-*.json`.

## Repetition source — findings only, no source picked

The Mukhtasar passage for every refrain is ayah 77's passage verbatim; it restates the refrain and
does not explain why it repeats. Surveyed all **15 English books** listed in the dumps manifest
(`scratch/english-books-55-13.md`, raw files and hashes in `scratch/`, downloaded 2026-10-04T00:45:46Z):

| book | 55:13 | commentary present in the file? | format | licence evidence in file |
| --- | --- | --- | --- | --- |
| 13640 Maududi "(With tafsir)" | translation only, with footnote **markers** `<sup foot_note=16073>2</sup>`, `16074` | **no — the note text is not in the file**; no footnotes endpoint found (`/api/v1/foot-notes/…`, `/footnotes/…` all 404; `translations.json.gz` is an availability index) | `<div>`/`<span>`/`<sup>`/`<br />`, "(55:13) " prefix | none |
| 13662 Khattab (with notes) | translation with one footnote marker `foot_note=29931` | **no**, same | `<div>`, `<sup>` | none |
| 13661 Khattab, The Clear Quran | translation only | no | `<div>` | none |
| 13603 Muhsin Khan | translation only | no | `<div>` | none |
| 13602 Ghali, 13604 Pickthall, 13605 Yusuf Ali, 13638 Sahih Intl (dup), 13644 Abdul Haleem, 13645 Taqi Usmani | translation only | no | `<div>` | none ("licentious" false positives in 13604/13644) |
| 1948 (unnamed English), 27811 Rowwad, 27833 Adel Salahi | translation only | no | plain | none |
| 1947 Saheeh International | translation + footnote 1594 | the footnote explains the **dual** ("you two", mankind and jinn), not the repetition | plain, `<br />` footnote block | none |
| 27824 Mukhtasar | ayah 77's passage reused | restates, does not explain the repetition | plain, "77. " prefix | none |

**Conclusion:** none of the English books on quranpedia.net/dumps carries, in the downloadable file,
a passage that explains why the refrain repeats. Maududi's and Khattab's notes exist only as IDs.
The decision on a source is Mo's; until then the repetition route answers with the ayah's
translation and meaning and states that no retrieved source explains the repetition.

## Integrity

- The model is only ever asked for one enum value. It never sees a passage and never writes text.
- Every answered question cites the IDs of the passages actually retrieved; rulings are referred;
  off-topic questions are declined. `EngineTests.passagesAreVerbatimCorpusText` asserts every
  displayed passage is byte-identical to a corpus text.
- Source texts stay local and gitignored; the public repository gets `tools/fetch-sources.py` and
  the pinned hashes.
