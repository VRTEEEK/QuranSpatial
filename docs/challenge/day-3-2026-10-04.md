## 3. Improvements, tuned on dev.json only — results after each change

- **Safety layer** (`RulingSafetyGate`): runs before any router; refers anything that looks like a
  ruling (halal/haram, permitted/forbidden, "am i allowed", "is it ok to", "do i have to", "is it
  required", prayer/fasting/wudu/zakat/riba…) or a personal situation brought for judgement ("my boss",
  "at my shop", "i missed", "cheat", …). Biased to refer.
- **Hybrid** (`HybridRouter`): gate → fragment check (≤1 substantive word, no "?") → rules only on
  high-confidence cues (repetition, related, word, meaning, off-topic) → the on-device model → rules
  if the model refuses or errors.
- Three rounds: (1) gate + hybrid as first written; (2) gate narrowed ("can you", bare "sin",
  "prostrate" removed; "is it required / supposed to" added), fragment rule, more repetition cues,
  tighter model label text for related/word/unclear; (3) "supposed to" narrowed to the first person,
  related cues for "comes up again later / further down", word cues for "in the arabic / in this
  context", meaning cues for "is this about / being addressed / i don't get / why would…".
